# 功能介绍

无限画布是 Windows 原生桌面客户端（WinUI 3，代码在仓库 `desktop/`）。本文档介绍已经发布的主要功能；新做的、还在等测试确认的改动见[待测试](/zh-CN/docs/progress/pending-test)。

## 画布

- 画布列表里可以新建和打开多个画布，删除的画布进入回收站。
- Win2D 无限画布：空白处拖动即平移，按住 Shift / Ctrl 拖动框选，支持触控板手势；节点可拖动、缩放、连线和编组，撤销重做最多保留 100 步，自动保存。
- 节点分图片、视频、音频、文本、配方和分组几种，按种类用不同颜色区分图标、连线和小地图。
- 可从资源管理器拖入、导入或粘贴图片、视频、音频；导入和生成的文件按画布和种类编号（如 `图片-001.png`），节点标题跟随编号，直到手动改名。
- 左下角小地图，点击或拖动即可跳转。
- 多选后可一键同宽、同高、同宽高或编组，以第一个点选的节点为基准。
- 双击图片全屏预览；Ctrl+C 复制图片或文字；Ctrl+= / Ctrl+- 缩放，方向键微调位置。

## 生成

- 五家服务商直连：OpenAI、Google Gemini、火山方舟、xAI、千问都按各自官方原生协议调用，不走兼容接口。在设置里按服务商添加，请求由客户端直接发往服务商。
- 支持图片、文本和语音生成。配方节点汇总上游的文本和图片，统一选择模型和参数后生成。
- 适配各家模型的特色功能：Seedream 5.0 pro / flash 点选框选编辑、图层拆分与透明背景，GPT Image 2.5 涂抹蒙版局部重绘，GPT Image 与 Nano Banana 多轮对话改图，千问 3.0 pro 智能体改写、思考模式与种子。
- OpenAI「Responses 图像工具」以后台任务提交，代理断线不会让长时间生成失败；关闭客户端后重开画布会接着取回结果。
- 一次生成多张时，结果叠成一摞，点击展开、点「收起」收回，选中的那张做封面；失败的节点可一键「重试」。
- 参考图超过服务商官方上限时自动压缩到上限以内再发送，并在指令栏说明压缩情况。
- 模型默认显示去掉前缀和日期的简短名字，也可以自定义显示名称，实际请求仍用完整型号。
- 这个版本只能导入和播放视频，视频生成保存在 `video-models` 分支。

## 图片工具

选中一个有图的图片节点时，节点上方出现工具条，右键菜单也有同样的入口。结果都放进右侧的新节点，原图不改动：

- 局部编辑、裁剪、拆分、多角度重绘和反推提示词。
- 本地放大：用 Real-ESRGAN 在本机显卡上放大 2× / 4×，图片不上传。需要先把 Real-ESRGAN-ncnn-vulkan 放进数据目录的 `tools\realesrgan`。

## 资料库与画布文件

画布左侧的面板分两页，内容都只属于当前画布：

- 资料库：这个画布常用的图片、视频、音频，存在画布自己的 `library` 文件夹里；可从资源管理器拖入或点 + 导入，拖到画布或双击即可使用，节点右键「加入资料库」以节点标题命名。Agent 的 `library_list` / `library_place` / `library_add` 也只作用于当前画布。
- 画布文件：这个画布文件夹里的全部图片、视频、音频，已经不在画布上的会淡化并标「不在画布上」；单击在画布上找到用到它的节点，双击、拖动或右键可把不在画布上的文件放回画布（直接用原文件）。
- 标题栏可刷新（读入在资源管理器里新放入的文件），并一键打开当前页对应的文件夹。
- 删除规则：在画布上删除图片、视频、音频只去掉节点，文件留在画布文件夹里；只有在「画布文件」页删除才把文件移到回收站，画布上用到它的节点一起删除（会先确认）；这一步不能在画布上撤销，需要时从系统回收站还原文件，删除失败的文件会保留节点并说明原因。离开画布时只清理不再使用的蒙版。

## 提示词库

- 指令栏可一键打开本地提示词库：搜索、按标签筛选，点一条即填入提示词；可以保存当前提示词，也可以编辑或删除已有的。
- 提示词库保存在数据目录的 `prompts.json`，所有画布共用，只存本机。

## Agent 助手

- 画布右侧的「助手」通过 ACP 启动本机 Agent（默认 Claude Code、Kimi Code、Grok Build、DeepSeek Harness，命令可在设置里改）。对话即可让 Agent 读取画布、增删改节点、连线和发起生成，支持授权确认和停止，一次修改只记一步撤销。
- 客户端外的 Agent（如 Claude Code、终端里的 Kimi / Grok）可以把 `InfiniteCanvas.exe --mcp-bridge` 登记为 MCP 服务器，操作当前打开的画布；设置里的「允许外部 Agent 连接」可以关掉。
- 画布工具只走本机命名管道，只允许当前 Windows 用户连接，不开网络端口。Agent 自身的登录、模型与计费由各家 Agent 负责。

## 界面

- Windows 11 原生风格：亚克力窗口，强调色跟随系统，支持浅色、深色和高对比度主题，运行中也能切换。
- 单实例运行；有生成任务时，离开画布或关闭窗口前会先确认。

## 数据与安全

- 画布、媒体文件和设置都保存在 `%LocalAppData%\InfiniteCanvas`，每个画布一个文件夹，不会上传到任何服务器。
- API Key 用 Windows DPAPI 按当前用户加密保存，生成请求走系统代理设置。
- 未处理的异常记录在数据目录的 `crash.log`。

## 当前限制

- 只支持 Windows 10 1809 及以上，推荐 Windows 11。
- 没有云同步，画布只保存在本机。
- 视频生成不在这个版本里（见 `video-models` 分支），插件节点暂不做。
