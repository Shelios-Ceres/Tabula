# 快速开始

无限画布是 Windows 原生桌面客户端，代码在仓库的 `desktop/` 目录。

## 环境

- Windows 10 1809 及以上，推荐 Windows 11。
- .NET 10 SDK。首次编译会从 NuGet 下载 Windows App SDK、Win2D 等依赖。

## 编译与运行

在仓库根目录执行：

```bash
dotnet build desktop/InfiniteCanvas.sln
```

```bash
desktop/src/InfiniteCanvas.App/bin/x64/Debug/net10.0-windows10.0.22621.0/win-x64/InfiniteCanvas.exe
```

程序为非打包自包含形式，不需要另装 Windows App SDK 运行时。也可以用支持 .NET 10 的 Visual Studio 2026 打开 `desktop/InfiniteCanvas.sln`，选择 x64 直接运行。

## 首次使用

- 打开设置，在「服务商」里添加要用的服务商（OpenAI、Google Gemini、火山方舟、xAI、千问），填入 API Key，再拉取或添加模型。
- 回到画布列表新建画布，在生成面板选择模型即可生成。
- 想让 Agent 操作画布：在画布右侧打开「助手」，或者在客户端外的 Agent 里把 `InfiniteCanvas.exe --mcp-bridge` 登记为 MCP 服务器。

## 说明

- 画布、媒体文件和设置保存在 `%LocalAppData%\InfiniteCanvas`，不会上传到任何服务器。
- API Key 用 Windows DPAPI 按当前用户加密保存，生成请求由客户端直接发往服务商。
