# Quick Start

Infinite Canvas is a native Windows desktop client; its code is in the repository's `desktop/` folder.

## Requirements

- Windows 10 1809 or later; Windows 11 is recommended.
- .NET 10 SDK. The first build downloads Windows App SDK, Win2D and other dependencies from NuGet.

## Build and run

From the repository root:

```bash
dotnet build desktop/InfiniteCanvas.sln
```

```bash
desktop/src/InfiniteCanvas.App/bin/x64/Debug/net10.0-windows10.0.19041.0/win-x64/InfiniteCanvas.exe
```

The app is unpackaged and self-contained, so no separate Windows App SDK runtime is needed. You can also open `desktop/InfiniteCanvas.sln` in Visual Studio 2026 with .NET 10 support and run the x64 configuration.

## First run

- Open Settings, add the vendors you use under "服务商" (OpenAI, Google Gemini, Volcengine Ark, xAI, Qwen), enter their API keys, then fetch or add models.
- Go back to the canvas list, create a canvas, and pick a model in the generation panel to generate.
- To let an agent work on the canvas, open "助手" on the right of a canvas, or register `InfiniteCanvas.exe --mcp-bridge` as an MCP server in an agent outside the client.

## Notes

- Canvases, media files and settings are stored in `%LocalAppData%\InfiniteCanvas` and never uploaded to a server.
- API keys are encrypted for the current user with Windows DPAPI, and generation requests go straight from the client to the vendor.
