# Report a Vulnerability

See [SECURITY.md](https://github.com/Shelios-Ceres/infinite-canvas/blob/main/SECURITY.md). Do not post exploit details, private API keys, sensitive screenshots, or real user data in a public issue.

Use [GitHub private vulnerability reporting](https://github.com/Shelios-Ceres/infinite-canvas/security/advisories/new). If it is unavailable, open a public issue asking for a private contact channel, without exploit details.

Include the affected version or commit and your Windows version, reproduction steps, impact and prerequisites, redacted logs or proof of concept, and whether locally stored canvases or media, API key storage, AI provider configuration, the local Agent connection, or network requests are involved.

The project prioritizes vulnerabilities caused by repository code or defaults, including sensitive-data exposure, file processing, import and recycling, access control of the local Agent connection, and supply-chain risks. Problems confined to third-party services or local agents (such as Claude Code), leaked user credentials, phishing, and account recovery are normally outside scope.
