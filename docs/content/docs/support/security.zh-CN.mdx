# 漏洞提交

安全策略英文原文见 [SECURITY.md](https://github.com/Shelios-Ceres/infinite-canvas/blob/main/SECURITY.md)。

请不要在公开 Issue 中直接发布漏洞细节、可利用代码、私密 API Key、截图中的敏感信息或真实用户数据。

## 提交流程

请使用仓库的 [GitHub 私密漏洞报告](https://github.com/Shelios-Ceres/infinite-canvas/security/advisories/new)。如果暂时无法使用，可以先开一个公开 Issue 请求维护者提供私密联系方式，但不要在 Issue 中写入漏洞细节。

## 建议提供的信息

- 受影响的版本、提交或分支，以及 Windows 版本。
- 清晰的复现步骤。
- 漏洞影响、攻击场景和触发条件。
- 已脱敏的日志、截图或 PoC。
- 是否涉及本机保存的画布或媒体文件、API Key 存储、服务商配置、本机 Agent 连接或接口请求。

## 范围说明

项目会优先处理由本仓库代码或默认配置导致的敏感信息泄露、文件处理、导入与回收、本机 Agent 连接的权限控制和供应链风险。

第三方模型服务、本机 Agent（如 Claude Code）自身的问题、用户自行泄露的 API Key、纯社工钓鱼或账号找回问题通常不属于本项目漏洞范围。
