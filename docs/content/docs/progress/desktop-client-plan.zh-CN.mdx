# WinUI 3 桌面客户端规划

桌面客户端位于仓库 `desktop/`，用 C# + WinUI 3 原生重写画布，不再依赖浏览器、本地代理或 Docker。原来的网页版及其配套工具已从仓库移除，需要参考时查 git 历史。

## 技术栈

| 层 | 选型 |
| --- | --- |
| 框架 | .NET 10、Windows App SDK 1.8（WinUI 3），非打包自包含运行 |
| 材质 | Windows 11 原生风格：窗口 `DesktopAcrylicBackdrop`，画布半透明透出亚克力，浮动工具栏与面板用通透亚克力（`GlassBrush` / `GlassThickBrush`）加系统投影，强调色跟随系统，按节点种类的多彩配色，跟随系统浅色 / 深色 |
| 画布 | XAML 节点层 + Win2D 网格与连线层 + Win2D 选框 / 连线草稿层，只实例化视口附近的节点 |
| 存储 | `%LocalAppData%\InfiniteCanvas`：每个画布一个文件夹（`project.json` + `assets/` 媒体文件），设置为 `settings.json` |
| 密钥 | API Key 用 Windows DPAPI 按当前用户加密保存，请求由客户端直连服务商，走系统代理 |

## 目录

```
desktop/
├─ src/InfiniteCanvas.Core/       # 画布模型、连线规则、撤销历史、项目与设置存储、模型家族能力
├─ src/InfiniteCanvas.Providers/  # 五家服务商原生适配
├─ src/InfiniteCanvas.App/        # WinUI 3：Pages（画布列表、画布、设置）与 Board（画布引擎、节点、生成面板、生成调度）
└─ tests/InfiniteCanvas.Tests/    # 核心规则与各服务商请求 / 响应解析测试
```

## 服务商原生适配

渠道只有「服务商」一个维度，每家只用自己的官方协议，不走兼容接口。

| 服务商 | 图片 | 视频 | 文本 | 语音 | 模型列表 |
| --- | --- | --- | --- | --- | --- |
| OpenAI | Image API `/v1/images/generations`、multipart `/v1/images/edits`（可选 SSE 预览、`markup` 标注改图），或 Responses `image_generation` 工具；GPT Image 2.6 只走 Image API，另有 `complexity` 与 GIF / SVG 输出 | 不支持（Sora API 已于 2026-09-24 下线） | Responses API 流式 | `/v1/audio/speech` | `/v1/models` |
| Google Gemini | Interactions API（`user_input` 步骤、`response_format` 指定比例与尺寸、思考强度、Google 搜索） | Veo `predictLongRunning` + 轮询 + 带 `x-goog-api-key` 下载 | Interactions API 流式 | — | `/models` |
| 火山方舟 | `/api/v3/images/generations`（Seedream 5.0 pro/flash/lite、4.5、4.0；组图、流式、联网、推理接入点） | `/api/v3/contents/generations/tasks`（Seedance 2.5 / 2.0 / 1.0） | Chat API 流式 | — | 推荐列表 |
| xAI | `/v1/images/generations` 与 `/v1/images/edits`（`aspect_ratio`、`resolution`、`quality`，多图用 `images`） | `/v1/videos/generations` + 轮询 | Responses API 流式 | — | `/v1/models` |
| 千问（百炼） | DashScope `multimodal-generation` 同步接口（qwen-image-3.0 / 3.0-pro / 2.1-pro，`W*H` 尺寸、反向提示词、提示词改写） | 暂未接入 | DashScope `text-generation` / `multimodal-generation` SSE | — | 推荐列表 |

视频一列目前不在 main：视频生成（含千问万相 2.7）整体保存在 `video-models` 分支，main 上视频节点只用来放导入的视频，需要时再合并回来。

模型能力（尺寸档位、比例、参考图上限、单次张数）统一在 `desktop/src/InfiniteCanvas.Core/Models/ModelFamilies.cs` 按模型家族声明，取值来自各家最新官方 API 参考。

## 实现说明

- 撤销重做按快照记录，最多保留 100 步；生成中的节点不受撤销影响。
- 生成请求不设客户端超时；`video-models` 分支的视频轮询为 2.5 秒 × 360 次，超时后保留任务 ID，重新打开画布继续查询。
- 图片节点直接显示原图，不按屏幕尺寸解码缩略图。
- 客户端没有浏览器的跨域限制，请求直接发往服务商，不需要本地转发代理。
