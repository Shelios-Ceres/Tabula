# Pending Tests

- Desktop GPT Image 2.6: `gpt-image-2.6-flare` (fast) and `gpt-image-2.6-sunburst` (detail and consistency across edits) are added and recommended, and new installs default to 2.6 Flare. Quality includes xhigh / max; a new "复杂度" (complexity) setting defaults to high, with low / medium: low suits focused edits, high suits dense text and complex layouts. Output formats add GIF (2–64 frames, 20–2000 ms per frame; blank keeps the official 9 frames and 200 ms) and SVG (one picture per request, more run as separate requests); both are text-to-image only without streaming previews, and transparent backgrounds need PNG / WebP. 2.6 uses the Image API only: its model pages list no Responses support, so the generation panel hides the call mode and other Responses options for it, and nodes left on Responses are sent through the Image API. Prices follow the model pages ($5 text input, $30 image output per 1M tokens); with no per-image table, the estimate uses the last run with the same settings. Local editing adds "标注" (markup, GPT Image 2.5 / 2.6): draw red circles or sketches where the picture should change; it is saved as a transparent layer `标注-001.png` and sent as `markup` with the edit. Mask and markup are either-or, and unreferenced markup is pruned with masks when leaving a canvas. The canvas shows SVG (import, generation, library thumbnails, full-screen preview, canvas covers); crop, split, multi-angle, local upscaling, prompt extraction and local editing are hidden for SVG, and an SVG used as a reference is drawn to PNG at its own size first (1024×1024 when it declares none). GIF nodes play their animation. Verified: the build has 0 warnings and 0 errors and 150 unit tests pass (2.6 request fields, GIF / SVG limits, markup upload and its exclusion with masks, SVG sizes and markup pruning). The client was not launched and no live account was used: check the generation panel and the markup tool by hand, and confirm with a real account whether 2.6 accepts masks and transparent backgrounds, whether the default GIF size fits the pixel budget, and what size SVG results come back at.
